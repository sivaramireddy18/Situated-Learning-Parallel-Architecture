Hazard and forwarding logic

Load-use RAW: I2 requires R1 from I1. Because a load value is available after MEM, I2 cannot use it in EX in the immediately following cycle. The control unit freezes PC and IF/ID and inserts a bubble into ID/EX.

ALU RAW: I3 requires R3 from I2. With forwarding ON, EX/MEM supplies the result directly to I3 EX. With forwarding OFF, the simulator inserts additional wait cycles before I3 executes.

Embedded-system interpretation

At 200 MHz, one clock is 5 ns. The load-use bubble adds one 5 ns cycle in this simplified model. If dependencies occur repeatedly in a high-rate control loop, stalls consume timing budget and can reduce real-time margin.
