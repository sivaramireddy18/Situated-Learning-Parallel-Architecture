5-stage RISC pipeline: hazard to timing analysis

LW → ADD → SUB demonstrates RAW dependency detection, a load-use stall and forwarding.

The LW → ADD dependency is the load-use RAW hazard.

Hazard analysis

  • I1 → I2: RAW dependency on R1.
  • I2 → I3: RAW dependency on R3.
  • The load result is not available early enough for I2's EX stage, so one bubble is required.
  • Forwarding avoids an additional stall between I2 and I3.

Industry interpretation

For control-oriented workloads, peak IPC is only one metric. Engineers also care about latency, memory behavior, interrupt effects and deadline margin.

Key lesson: repeated bubbles inside a high-rate loop can consume real timing margin.
