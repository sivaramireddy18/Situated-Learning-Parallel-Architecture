Press Clock +1. The simulator advances actual instruction state; it does not reveal future stages before they occur.

Stage model: IF fetch · ID decode/register read · EX ALU/address generation · MEM data memory · WB register writeback.

Realistic behavior

  • Each clock advances the pipeline by one stage.
  • The load-use hazard holds I2 in ID for one cycle.
  • The following fetch is also held during the interlock.
  • A bubble enters EX during the stall cycle.
  • I2 → I3 is resolved with forwarding, avoiding another stall.

Embedded-system interpretation

For a 200 MHz controller, one clock is 5 ns. The single load-use bubble therefore consumes 5 ns in this simplified model. Repeated dependencies inside a high-rate control loop can accumulate into measurable latency.
